# Team AI Assistant

Мини-дашборд AI-ассистента для продуктовой команды: задаёте вопрос, Claude отвечает в реальном времени, ответ красиво оформлен, его можно скопировать, а последние 5 запросов сохраняются в истории.

## Возможности

- **4 режима с отдельными промптами**: «Объяснить», «Саммари» (выжимка + action items), «Написать» (готовый текст для чата или письма), «Код» (ревью и решения).
- **Стриминг ответа**: текст появляется по мере генерации, генерацию можно остановить.
- **Markdown-рендер**: заголовки, списки, таблицы, подсветка кода, кнопка копирования у каждого блока кода.
- **Копирование ответа** работает и при открытии по IP в локальной сети (фолбэк для небезопасного контекста).
- **История из 5 последних запросов** в localStorage: открыть ответ без повторного запроса, удалить запись, очистить всё. Синхронизируется между вкладками.
- **Обработка ошибок**: нет ключа, неверный ключ, лимиты, таймаут, нет сети, обрыв соединения, пустой или обрезанный ответ. Каждая ошибка показывается понятным текстом с кнопкой «Повторить».
- **Вход по паролю** для публичного деплоя: подписанная httpOnly-cookie, лимит попыток, кнопка «Выйти».
- Примеры вопросов на пустом экране, отправка по `Ctrl+Enter`, тёмная тема, адаптивная вёрстка.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000.

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | Ключ Claude API ([console.anthropic.com](https://console.anthropic.com/settings/keys)) или ключ совместимого прокси |
| `ANTHROPIC_BASE_URL` | Адрес API. Для прокси — его адрес без `/v1` |
| `ANTHROPIC_MODEL` | Модель, по умолчанию `claude-opus-5` |
| `ACCESS_PASSWORD` | Пароль для входа. Пусто — вход отключён (удобно локально) |

## Архитектура

```
src/
  app/
    page.tsx              — точка входа страницы
    api/ask/route.ts      — серверный вызов Claude: валидация, rate limit, стриминг, ошибки
    api/session/route.ts  — вход и выход по паролю
    login/page.tsx        — страница входа
  proxy.ts                — пускает к приложению и API только с валидной сессией
  components/
    AssistantDashboard    — композиция страницы и состояние
    QuestionForm          — ввод вопроса, режимы, отправка/остановка
    AnswerCard            — ответ: загрузка, стрим, ошибка, копирование
    HistoryPanel          — последние 5 запросов
    LoginForm, Markdown, CopyButton, EmptyState, ModeSelector, icons
  hooks/
    useAskAI              — запрос и чтение потока, отмена, состояния
    useHistory            — подписка на историю через useSyncExternalStore
  lib/
    prompts.ts            — системные промпты (только на сервере)
    modes.ts              — описание режимов для UI
    anthropic.ts          — клиент Claude и настройки модели
    history.ts            — localStorage-стор для useSyncExternalStore
    auth.ts               — проверка пароля и сессии (HMAC, сравнение за постоянное время)
    rate-limit.ts, clipboard.ts, config.ts, types.ts
```

## Ключевые решения

| Решение | Почему |
|---|---|
| Next.js: фронт и API в одном проекте | Один репозиторий и один деплой; ключ хранится на сервере и не попадает в браузер |
| Стриминг ответа | Первые слова появляются почти сразу, ожидание ощущается заметно короче |
| Ожидание первого события перед ответом клиенту | Ошибки авторизации и лимитов приходят обычным HTTP-статусом с понятным текстом, а не обрывом стрима |
| Промпт = общая роль + режим | Ассистент специализирован под команду; формат ответа задан под каждую задачу |
| `effort: "medium"` | Для Q&A важнее скорость, чем максимальная глубина рассуждений |
| `fallbacks: "default"` | Если модель отклонит запрос, API автоматически повторит его на подходящей модели |
| Rate limit (10 запросов в минуту) и `max_tokens` | Защита бюджета при публичной ссылке |
| Пароль через `proxy.ts` и cookie | Публичная ссылка не тратит баланс API у посторонних; без пароля проект запускается как раньше |
| История в localStorage | Для пяти записей БД не нужна; данные остаются у пользователя |
| Своя реализация копирования | `navigator.clipboard` не работает по http://IP, поэтому есть фолбэк |
